# Dwellora

Dwellora is a modern apartment budgeting and home expense management project designed to help tenants, roommates, and landlords track spending, manage shared costs, and stay on top of monthly apartment finances.

Live demo: https://apartment-budget-com-mrls.bolt.host/

## Overview

This project focuses on making apartment budgeting simple and transparent. Users can monitor rent, utilities, groceries, maintenance costs, and shared household expenses in one place.

The goal of Dwellora is to reduce confusion around apartment costs and help residents manage expenses more effectively.

## Key features

- Monthly apartment budget tracking
- Shared expense management for roommates
- Expense categorization
- Rent and utility cost monitoring
- Simple dashboard for financial visibility
- Responsive interface for desktop and mobile use
- Easy-to-understand summaries of household spending

## Why this project matters

Apartment living often involves multiple people, recurring bills, and shared responsibilities. Dwellora helps keep those costs organized and visible so everyone can track what is due, what has been paid, and how much remains in budget.
